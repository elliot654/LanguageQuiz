# LanguageQuiz

A simple Android flashcard-style quiz app for learning new languages.

## Description

LanguageQuiz is an Android app designed to help users practice vocabulary in a target language by displaying a word in the selected language, prompting the user for an answer, and immediately provideing feedback. The quiz then continues in a continuous loop, allowing for ongoing vocabulary practice.

### Features
- promopts user to submit attempt or skip a given question
- highlights correct answers, corrects incorrect ones
- offers 12 languages
  - Danish
  - French
  - German
  - Icelandic
  - Italian
  - Norwegian
  - Polish
  - Portuguese
  - Russian
  - Spanish
  - Swedish
  - Welsh 

## Getting Started

### Dependencies

*Android Studio (latest stable version recommended)
*Android SDK (API level XX or higher)
*Gradle (included with Android Studio)
*Android device or emulator running Android X.X+

### Installing
1. Clone the repository
2. Open the solution file in Android Studio
3. Build the project
